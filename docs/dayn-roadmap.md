# Day N：快速启动与持续实践

Day1定卖什么，Day2定怎么卖，Day3完成建站与社媒运营之前的必要准备，之后直接搭建独立站、装修社媒并进入运营。Day是阶段而非一个日历日，按实际进度完成。按用户授权将记录保存到私有位置并检查上传范围，后续用记录续接，不设固定结束日期。

| 节点 | 工作 | 产出 |
|---|---|---|
| [Day 1：快速起步](../days/Day01-快速起步/TASK.md) | 访谈个人条件，研究至少10个具体产品，通过多轮询问和补充调研筛到一个优先产品 | 候选比较、多轮筛选、最终产品的详细外贸深度调研报告 |
| [Day 2：销售方案](../days/Day02-开始实施/TASK.md) | 报价测算、客户渠道、必备独立站首版、展示话术、交付收款与潜在客户研究 | 一页行动摘要、站点方案与文案、模板、客户名单、分优先级动手与验证清单 |
| [Day 3：开工准备收口](../days/Day03-产品与供应落地/TASK.md) | 核实产品与供应，备齐图文、品牌素材、页面和首批社媒文案，落实邮箱、账号与适用收款准备 | 可用开工包、准备检查、未决项及下一阶段建站与社媒操作入口 |
| [后续：持续实践](../days/DayN-持续实践/TASK.md) | 按真实前提继续供应、样品、站点、账户、客户与交付，遇到问题解决问题 | 行动、反馈、解决办法、验证和下一步 |

Day1完成选品与研究，Day2形成方案，Day3将当前首版建站与首轮运营需要的材料和账号真正备齐，缺口解决后进入实操；不继续堆准备报告。供应回复、样品和账户审核按实际进度记录，分别判断是否阻断建站、内容发布或真实收款接单，不伪造完成。独立站必备，但实际页面搭建和持续社媒运营在Day3后的阶段开展。

## 持续流程

目标 → 行动 → 结果与问题 → AI研究和解决 → 验证效果 → 更新记录 → 下一轮。

利用用户已确认的AI、自动化和其他能力提高效率。重复工作出现时随时自动化，不把搭整套系统设成启动门槛。客户开发与持续跟进长期进行，报价、样品、收付款、履约与售后按实际需求推进，不设Day 30终点。

## 视频

第一天记录访谈、选品研究、完整比较及用户选择。后续展示真实操作、AI和自动化处理的环节、实际问题、解决过程与验证结果。保留失败、未知和更正，草稿与模拟不算真实成交或客户反馈；不强制每天一集。

- [dayn-quick-start](../days/Day01-快速起步/dayn-quick-start/SKILL.md)：先询问必要条件，AI主动研究、推荐，用户做关键选择，再继续执行。
- [dayn-start-action](../days/Day02-开始实施/dayn-start-action/SKILL.md)：沿用Day1的产品，AI主动研究并制定销售方案，用户做关键选择，交付实践启动包。
- [dayn-product-launch](../days/Day03-产品与供应落地/dayn-product-launch/SKILL.md)：先弄懂产品和客户问题，再按授权询价，用可靠资料推进产品图、问答与独立站内容；不为展示工具改变业务顺序。
- [dayn-practice-loop](../days/DayN-持续实践/dayn-practice-loop/SKILL.md)：先询问必要条件，AI主动研究、推荐，用户做关键选择，再继续执行。
