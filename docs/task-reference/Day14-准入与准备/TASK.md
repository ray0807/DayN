# Day 14：准入与准备

## 今天要完成

明确开展业务前需核实的条件。

## AI 主动完成

查询适用官方要求，整理已核实、待核实及不适用项。可研究的问题不要交回用户；涉及时效信息先查证，保留直接来源与适用条件。

## 用户负责决定

继续核实、调整方向或引入专业服务。AI 提供少量选项、主要代价与推荐；用户已决定的事项不重复确认。

## 今天的产出

准备事项清单。分别标记已确认事实、AI建议、用户决定与待验证项；不要求当天解决所有未知。

## 使用的 skill

主要使用 [$b2b-trade-readiness](../../../skills/b2b-trade-readiness/SKILL.md)。需要把成果拍成视频时，再使用 [$b2b-real-content-log](../../../skills/b2b-real-content-log/SKILL.md)，它负责记录而非替代业务调查。

## 启动提示词

> 使用 $b2b-trade-readiness 帮我推进 Day 14：准入与准备。根据已有信息主动完成研究、比较与材料整理，给出依据和推荐，只问我个人条件与关键取舍。先完成这一步，不自动推进到下一天。

## 真实记录提醒

没有产品或地区信息不能给确定认证、税费结论。

## 完成与续接

保存当次实际成果、来源、尚未确认的问题和下一项行动。重大选择尚未确定时，先完成不依赖它的调查，等待用户判断，不代填答案。下一次按实际进度继续，不为 Day 编号强行跳过前提。
