# Day 2：能力与资源

## 今天要完成

盘点能力与供应资源。

## AI 主动完成

整理经历、工具、供应资源及缺口，分析哪些资源有助于起步。可研究的问题不要交回用户；涉及时效信息先查证，保留直接来源与适用条件。

## 用户负责决定

补充真实经历、人脉和可接触资源。AI 提供少量选项、主要代价与推荐；用户已决定的事项不重复确认。

## 今天的产出
