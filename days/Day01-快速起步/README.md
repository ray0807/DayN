# Day1：选品研究与个性化推荐

**你提供真实条件并做关键选择，AI负责思考、调研和比较。**

最终交付是一份研究报告：至少10个具体商品候选、统一比较、通过多轮询问和补充调研筛到一个优先产品，以及暂不推荐的理由。供应商开发属于后续实施阶段。

## 使用入口

可执行技能：[dayn-quick-start/SKILL.md](dayn-quick-start/SKILL.md)。概览：[TASK.md](TASK.md)。

~~~text
使用 $dayn-quick-start，先用弹窗连续了解我的实际条件。
信息足够后主动研究国内外多个商品类目，给出至少10个具体产品候选。
统一比较需求、买家、差异化、竞争、学习及合规负担、样品与资金要求，通过多轮询问和补充调研筛到一个优先产品并说明依据和排除理由。
先完成整体研究，再让我选择深入方向。Day1不找或联系供应商。
~~~

未安装时要求Agent直接读取本目录的SKILL.md。存放文件不代表自动安装，联网与执行能力取决于工具环境。

## 整体流程

弹窗了解 → 回答后分析与补问 → 将条件转成筛选标准 → 研究多个类目 → 完成至少10项产品比较 → 推荐并解释 → 弹窗选择深入方向。

每轮沿用已有信息，需要补问时实际发出弹窗；信息足够就研究，不要求反复发送“继续”。关键个人条件未知时不代填，不携带其他使用者的经验和资源。

## 了解哪些条件

经历、所在地区、时间和预算、实际资源、语言和沟通、经营主体情况、竞争偏好、愿意学习及承担的工作、样品和垫付边界。每次只问影响当前判断的必要信息，不让新手回答行业和市场专业题。

偏好不同，筛选标准不同。标品不一定只能卷价格，定制也不一定有高利润；AI要查具体采购场景、竞争及可建立的价值，不能只说产品容易入门。

## 报告内容

| 部分 | 内容 |
|---|---|
| 个人分析 | 已确认条件及回答依据，优势、限制、未知与筛选逻辑 |
| 候选覆盖 | 至少10个实质不同的具体产品，不用颜色或尺寸凑数 |
| 统一比较 | 买家与用途、初步市场、证据、差异化、竞争、学习与合规、样品与资金、个人适配 |
| 重点推荐 | 逐轮保留与排除的理由，最终一个优先产品、困难及未验证前提 |
| 排除项 | 暂不推荐的方向与依据，不只展示有利信息 |
| 选择节点 | 完整比较后请你选择深入方向，整理后续待办 |

来源就近标注直接链接、日期与适用范围。网页线索不等于采购需求，供应自述不等于已核实能力。证据不足的标待验证，不为达到数量夸大机会、利润或成交概率；受用户限定范围影响无法覆盖10项时先解释并询问是否扩大。

## Day1不做什么

不把供应商名单、联系方式和联系教程作为最终交付，不写供应合作申请，不开展联系、打样或合作谈判。可以查看产业、供货和样品特点用于评估产品，但不以先取得供应合作为选品报告的前提。

## 结束与后续

至少10个候选是中间成果。之后持续弹窗询问、分析取舍、补充调研并缩小范围，用户确认一个优先产品并完成其详细外贸深度调研报告后才完成Day1；保留选择理由、未知与后续验证计划。用户要求进入 [Day2](../Day02-开始实施/TASK.md) 时再制定销售方案。

准备共两天，Day1定卖什么，Day2定怎么卖，外部条件在实践中验证。研究报告默认在聊天交付，要求保存时再写入授权位置；私人资料不填进公开技能。录制脚本仅在聊天提供，不保存到项目或上传GitHub。

## 从候选池到唯一优先产品

10余个候选 → 弹窗了解取舍 → 分析保留与排除 → 补充国内外研究 → 缩小到少量候选 → 用户确认一个优先产品。数量和轮数可调整，不能强行淘汰或未经确认代选。这里的询问对象是本技能使用者，不在Day1对外联系客户。

## 最终产品的详细外贸深度调研

筛到一个产品是中间节点，确认后AI主动继续研究：产品定义和规格、全球贸易与需求、目标市场比较、企业买家和采购流程、竞争及差异化、产业与生产特征、成本报价及资金情景、物流交付、产品与目标市场合规、市场进入策略、风险与后续验证。

最终交付完整报告、数据来源、比较与测算表，以及结合当前用户条件的推荐和成立前提。未知数据不编造，行业大类统计不冒充细分市场，公开线索不冒充真实需求。供应商联系仍属后续阶段。报告默认在聊天中交付，只有用户要求保存时才写文件。
