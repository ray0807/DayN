# Day1：从实际情况出发，开始商品外贸

面向普通外贸新手。你不需要先懂行业、选品、海外市场或出口手续；AI先问清你的实际条件，再主动联网调研、解释和推荐，你做关键选择。

可执行入口：[dayn-quick-start/SKILL.md](dayn-quick-start/SKILL.md)。概览：[TASK.md](TASK.md)。

## 如何启动

~~~text
读取 days/Day01-快速起步/dayn-quick-start/SKILL.md。
把我当作普通商品外贸新手，先分轮了解我的真实情况，每轮最多三个问题。
根据我的回答，主动联网调研实物产品、供应、海外买家和目标市场。
告诉我适合先试什么、为什么、具体怎么做，再让我做关键选择。
不要在调研前要求我选择业务组合，不预填个人能力和资源。
~~~

直接读取文件即可使用其中指导；仅放在本目录不代表已自动安装。联网和执行权限取决于工具环境。

## 先了解什么

- 所在地区、工作和产品经历，以及能否接触工厂或供应商。
- 可持续业务时间、起步预算和可接受的工作负担。
- 语言沟通情况、是否有经营主体、已有产品偏好或明确限制。
- 已经明确的条件不重复问；未提供的标待确认。

每轮收到回答后解释其影响，再补必要缺口。没有经验、供应资源或明确产品也可以开始分析；行业和市场判断由AI研究，不让新手自行回答专业题。

## AI要做什么

结合上述条件，主动研究具体商品、真实供应线索、真实海外企业案例、目标市场、成本及关键限制，再比较少量候选。

推荐必须说清：适合你的理由、资料依据、主要困难、尚未核实的条件，以及建议如何开始。候选围绕商品外贸；AI和自动化是辅助工具，不把用户带去AI服务、软件外包或SaaS出海。

## 你要做什么

提供真实个人条件，听懂比较理由后，选择优先验证哪个方向、是否接受对应投入与取舍。选择前先获得分析，不凭空选行业或国家。

## 第一阶段的产出

起步条件与回答依据、候选比较与来源、AI推荐、用户选择、首批供应和买家候选、沟通草稿及下一项验证动作。未回复、未报价、未核实的条件如实保留。

准备阶段整体按1–2天安排；外部回复和具体交易条件随实施跟进。随后进入 [Day2](../Day02-开始实施/TASK.md) 和 [持续实践](../DayN-持续实践/TASK.md)，遇到问题研究解决，再验证效果，没有固定终点。
