# Day 1：快速起步

通过 AI Agent 了解自己的起点，主动调研并比较外贸方向，选择一个值得开始验证的业务组合。

**AI负责思考、调研、比较和推荐；你提供真实条件，做关键选择。**

准备阶段整体按1–2天安排。Day1合并原来的投入、能力资源、候选行业、行业比较和企业客户类型，形成起点后尽快实施；后续通过实际业务持续完善。

## 从这里开始

本Day的可执行技能是 [dayn-quick-start](dayn-quick-start/SKILL.md)，任务概览见 [TASK.md](TASK.md)。

把下面的提示词交给能读取项目文件、具有联网能力的AI Agent：

~~~text
先读取 days/Day01-快速起步/dayn-quick-start/SKILL.md，按其中流程推进Day1。

先沿用会话里的已知条件，只向我询问你无法自行取得的个人信息和关键取舍，每轮最多三个问题。
根据我的回答，主动联网调研外贸候选方向，比较方案、给出推荐和依据，让我做选择。
专业问题由你思考、解释和调查，不要求我先懂行业、市场或外贸手续。
我选择后，整理起步表、待验证事项和下一项可执行行动。

准备整体按1–2天安排，不为了天数拆任务，不把所有未知都解决作为开始实施的前提。
~~~

技能文件可直接作为Agent的工作指导。仅存放在本目录不代表已经被工具自动安装或识别；联网、执行及文件权限取决于实际使用环境。

## 双方怎么分工

| AI Agent主动完成 | 你提供或决定 |
|---|---|
| 整理会话已有条件，发现关键缺口 | 实际时间、预算、经历、资源和个人限制 |
| 解释外贸知识，联网查证专业问题 | 愿意承担什么工作，哪些负担不接受 |
| 研究行业、具体产品、企业客户，必要时比较目标市场 | 优先试哪个业务组合 |
| 比较供应、客户、成本和关键限制 | 接受哪些投入和取舍 |
| 给明确推荐、依据和待验证项，整理下一步 | 必要支出与对外承诺 |

AI不能把“需要用户决定”变成“请用户自行调研”。你不知道专业答案时，AI应先解释或调查；你还没有明确偏好时，AI应给具体选项帮助判断。

## 当前skill的执行流程

1. **读取已有信息。** 保留已经确认的B2B方向、能力、资源与选择，不重复问卷，也不推测未提供的条件。
2. **补问必要条件。** 优先了解持续投入的时间、现金上限、真实行业或供应资源、兴趣及不接受的工作。每轮只问影响当前分析的1–3项。
3. **主动联网调研。** 根据回答研究少量“行业—具体产品—企业客户类型”组合；目标市场影响判断时加入研究。
4. **比较并推荐。** 判断供应可接触性、产品学习与质量判断难度、样品及物流投入、客户可识别性、起订和交付条件、售后负担与关键准入限制。
5. **请你做关键选择。** 通常给2–3个可比方案，说明推荐理由、主要代价、未知项和可能改变推荐的证据。AI建议与用户决定分别记录。
6. **准备下一项实际行动。** 选择后整理起步表及首轮动作。需要等待供应或客户反馈的事项进入后续队列，其他可独立工作继续推进。

## 调研结果应该怎么看

候选应尽量具体到产品、企业客户及相关采购用途，避免只给“家居”“机械”等宽泛行业词。

关键结论应有直接来源，注明资料日期、查询日期及适用范围。缺少日期或证据时如实说明，不把网页线索当成客户需求，不把公开价格当成实际供货报价。

一份够用的比较结果可以采用下表，不要求制造精确评分：

| 候选组合 | 适配你的理由 | 供应与买家依据 | 主要投入和限制 | 待验证项 | AI建议 |
|---|---|---|---|---|---|

市场、政策、费用、物流和准入等变化信息需要实际联网查证。无法联网时，应明确哪些内容当前未核实，继续能独立完成的分析。

## Day1结束时应该得到什么

- **起步条件：** 真实投入、能力、资源及限制。
- **候选比较：** 少量业务组合、来源、适配理由和主要取舍。
- **初步选择：** 你明确选择优先探索的组合及理由；未选则保留待选择。
- **待验证事项：** 哪些判断还缺供应条件、买家反馈或其他证据。
- **下一项行动：** 做什么、希望取得什么信息、结果怎样影响后续判断。

知道“先试什么、投入边界、下一步怎么做”，就可以开始实施。若证据不足以选择，AI应指出关键缺口并推进验证，不强行替你定方向。

## 调研后提出的skill优化建议

以下是待用户决定是否写入skill的建议，本README没有修改技能正文：

- 候选比较明确包含“产品＋企业客户类型＋初步目标市场”。
- 每个候选同时查看真实供应线索与真实买家案例。
- 补充了解已有经营主体，并初步说明签约、收款和出口可能采用的路径。
- 你选择后，进一步整理首批供应与买家候选及沟通草稿，条件具备就开始验证。

当前执行规则以 [SKILL.md](dayn-quick-start/SKILL.md) 为准。

## 如何继续

进入 [Day2：开始实施](../Day02-开始实施/TASK.md)，准备首轮动作需要的资料、工具和沟通。条件具备时可以当天提前实施，不必等待第二天。

1–2天是初筛与行动准备的安排。供应回复、样品、开户、备案及具体交易要求等按实际进度跟进，关键条件在对应动作前落实。

随后进入 [DayN：持续实践](../DayN-持续实践/TASK.md)，持续开展行动、收集反馈、解决问题、验证效果，再进入下一轮，没有固定结束日期。

阶段结果可按 [决策记录模板](../../docs/decision-record-template.md) 整理。私人预算、客户与供应资料保存到授权的私有位置，不写入公开技能正文。实际发送、支出、下单、发布和承诺按已有授权执行。
