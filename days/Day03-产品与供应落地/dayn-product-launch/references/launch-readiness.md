# Day3开工前交接检查

目标：Day3结束后，用户打开工具即可开始独立站搭建和社媒装修运营，不需要重新选工具、找素材或从空白写文案。此表记录真实准备，不把网站上线或帖子发布提前算进Day3。

| 准备项 | 应交付的可用成果 | 实际位置或依据 | 当前状态 | 缺口是否阻断下一步 |
|---|---|---|---|---|
| 产品知识 | 用途、规格、优缺点、痛点、适用限制与客户FAQ | | | |
| 供应条件 | 实际询价和取得的回复、数量与价格条件、待确认项 | | | |
| 产品图片 | 有使用依据、已检查一致性、可用于首版的图片 | | | |
| 品牌资料 | 真实显示名、头像、封面、目标语言简介、联系方式 | | | |
| 邮箱与账号 | 邮箱收发及必要社媒和建站账户的实际访问情况 | | | |
| 网站内容 | 页面结构、可复制文案、图文对应、FAQ和询盘字段 | | | |
| 网站工具与域名 | 已选工具、账户、预算、域名现状与后续操作入口 | | | |

“有教程”不等于账号或素材已完成。只有草稿、参考不足或需要本人处理时明确标状态，不填假完成。

## 三种准备程度分别判断

1. **可以开始建站吗？** 必要工具可访问，有可用页面材料和清楚的下一步；域名未买时说明会在后续哪一步购买，不假定已持有。
2. **可以开始社媒装修与首轮发布吗？** 已选账号可用，有可直接使用的身份资料、图文与对应教程；未上线网站链接可以待补，不能造网址。装修就绪与发布资格分别核实。
3. **可以真实收款接单吗？** 另核实供货、产品要求、主体与收款履约条件；不能由“能建站”推定“能收款”。审核、样品及其他待办说明影响范围。

## 最后给用户

- Day3实际备齐了什么，具体存在哪里。
- 仍缺什么；属于开工阻断还是可以并行跟进。
- 下一阶段的第一项建站动作及直接入口、教程、现成文案图片和完成标志。
- 可以并行的社媒装修动作及首批内容位置。

查证和排障延续原技能规则，用户提问后解决问题并回到当前进度，不要求重新做准备。
